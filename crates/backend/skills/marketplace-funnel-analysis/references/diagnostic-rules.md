# Диагностические правила

- Рост верхнего этапа при падении orders означает ухудшение конверсии.
- Наибольший `drop_off` — основной кандидат для диагностики.
- Если нижний этап больше предыдущего, отметить `non_monotonic_funnel`.
- При нулевом предыдущем этапе конверсия не рассчитывается и возвращается `null`.
- Сравнение периодов выполнять только для одинакового набора фильтров.
- Сегменты с предупреждениями качества не использовать для рейтинга без оговорки.
