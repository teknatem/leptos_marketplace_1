# Правила качества данных

- Отрицательные значения недопустимы.
- `null` и отсутствие поля означают отсутствие данных, а не ноль.
- Все значения этапов должны быть конечными числами.
- Воронка обычно монотонно убывает; нарушение допустимо из-за разных источников,
  но обязательно попадает в warnings.
- Пустой marketplace, неизвестный marketplace и отсутствие orders являются ошибками.
- Для сравнения периодов labels периодов должны различаться.
